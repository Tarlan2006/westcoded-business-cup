# Mission Control: связный путь по сайту

## Что изменилось

- Вместо математического ParentGate — **🔒 Grown-ups** с удержанием 1,5 секунды. Кольцо показывает прогресс. Быстрый тап, отпускание, уход указателя, потеря фокуса или скрытие вкладки отменяют открытие. Enter и Space работают по тем же правилам. В `Parent.tsx` остался только Privacy.
- Первый визит сначала объясняет продукт, затем предлагает два коротких шага анкеты. Для возраста 1–2 второй шаг пропускается. Регистрации нет.
- Хаб начинает с одной рекомендации **Start here**, а ниже сохраняет привычные секции Move, Learn и Watch.
- После игры и миссии появился общий **Next up**: повтор, две другие подходящие активности и возврат в хаб.
- `App.tsx` хранит массив `history`. Back возвращает предыдущий экран и позицию прокрутки. 🏠 открывает хаб. Завершённые игры убираются из истории, поэтому Back с результата не возобновляет игру и не начисляет XP повторно.
- Общий `ActivityHeader` показывает Back, Home, название, однострочные хлебные крошки и XP. На телефоне название/крошки занимают отдельную строку, чтобы кнопки оставались крупными.

## Экран → кнопки → куда ведут

1. **Первый визит / Mission Control**
   - Объяснение: «Games, quizzes and videos that get kids moving and learning, so you get a few calm minutes».
   - Метки: No account · No camera · Progress stays on this device.
   - Step 1 of 2: age and time → **Next** → Step 2 of 2: where and what first.
   - **Back** на втором шаге → первый шаг с сохранённым выбором.
   - Возраст 1–2 → только возраст, время и кодовое имя → **See activities**. Нет лишних вопросов о месте и треке.
   - **See activities** → сохранение профиля → хаб.
   - **Privacy** → объяснение приватности → Back возвращает к той же незавершённой анкете.
2. **Хаб / Activities**
   - **Start here → Start** открывает рекомендованное занятие.
   - 6–8 + Think & learn → Ask Mission Control; 3–5 + Think & learn / Surprise us → Quiz.
   - In the car + Move → Roadtrip Spy; дома + Move → Scavenger Hunt.
   - 1–2 → Video library. Watch у 3–5 до квиза → Quiz с объяснением, как открыть видео; после квиза → Video library.
   - Карточки ниже открывают соответствующие игры, подготовку миссии или видеокаталог.
   - **🔒 Grown-ups**, удержание 1,5 секунды → Parent settings. Подпись Press and hold; aria-label: «Grown-ups settings, press and hold for one and a half seconds».
   - **Privacy** → Privacy → Back возвращает в хаб на прежнюю позицию.
3. **Parent settings**
   - Пояснение «Changes apply right away». Сохранённые изменения сразу используются при выборе активностей.
   - **Save changes** → сохранить профиль → хаб → плашка **Saved ✓**, `role="status"`, на 2 секунды.
   - **Back / Home** → хаб без сохранения незавершённых изменений.
   - Privacy → Back возвращает к тем же несохранённым настройкам.
4. **Подготовка и прохождение миссии**
   - Хаб → карточка Move → Mission setup → **Start mission** → существующая игра.
   - Back из миссии → предыдущий экран (обычно Mission setup). Home → хаб.
   - Pause / Resume / End mission продолжают использовать существующую логику миссии.
   - End mission / завершение времени → новый экран представления результатов `MissionSummary`, без изменения раундов, очков, записи истории и правил самой игры.
5. **Learn**
   - Quiz / Memory / Tic-tac-toe → Back возвращает предыдущий экран; Home ведёт в хаб.
   - Ask → вопрос → ответ → **Quick quiz about this** → квиз по теме → Back возвращает **к тому же ответу Ask**, а не к пустой форме. Ответ сохраняется только в памяти компонента; вопросы не добавляются в хранилище профиля.
   - Sketch Artist по-прежнему доступен только 6–8 и загружается лениво. Его Back подключён к истории приложения; сам модуль не редактировался.
6. **Результат / Next up**
   - Сохраняются XP, общий прогресс и серия дней.
   - **Play again** → новое прохождение той же активности с новым ID; квиз сохраняет тему, миссия — режим и длительность.
   - **Try next** → два других разрешённых занятия. У 3–5 после квиза первой идёт **Watch your video reward**, второй — Memory.
   - **Back to activities / Back / Home** → хаб. Переход не повторяет начисление XP.
7. **Watch**
   - 1–2: только видео, без игровых карточек.
   - 3–5 до первого квиза: карточка видео объясняет ограничение и открывает квиз.
   - После квиза видео остаётся доступным в сохранённом профиле.
   - Каталог → карточка ролика → проигрыватель → Back → каталог → Back → предыдущий экран.
8. **Подтверждение выхода**
   - Mission, Quiz, Memory и Tic-tac-toe: первые 5 секунд выход свободный; затем Back / Home открывают **Leave this game?**.
   - **Keep playing / Escape** → остаться в текущей игре без сброса; **Leave game** → выполнить запрошенный переход.
   - Модальный `<dialog>` удерживает клавиатурный фокус. Начальный фокус — Keep playing.
   - Перезагрузка может открыть хаб; профиль и завершённые активности сохраняются как раньше.

## Решение по «10 min planned»

Убрали подпись из карточки ребёнка: она выглядела как оставшийся таймер, хотя показывала только настройку длительности. Время по-прежнему выбирается в анкете, хранится в профиле и предлагается в Mission setup. Скрытого обхода удержания Grown-ups через подпись времени теперь нет.

## Реализация и границы

- Новые общие компоненты: `GrownUpsButton`, `NextUp`, `LeaveGameDialog`, подбор рекомендаций `activitySuggestions`.
- `ActivityNavigation` передаёт навигацию в существующие заголовки без правки внутренних файлов игр. Back теперь является навигацией, а не командой Pause/End из старого заголовка Mission; отдельные игровые кнопки Pause/End сохранены. Выход через Back не собирает неполученную награду.
- В памяти остаются только пассивные экраны Ask под его квизом и анкета/настройки под Privacy. Игры с таймерами за другими экранами не хранятся.
- Для итогов миссии используется новый `MissionSummary.tsx`. Старый экспорт Results в запрещённом `Mission.tsx` не изменён и из App больше не используется.
- Не менялись worker, audio, voice, game, games, shared/types, content, scripts, package.json и lockfile. Новых зависимостей нет.

## Нужны правки в других файлах

Основной путь работает в разрешённой зоне. Отдельно, с владельцами модулей, можно завершить унификацию:

1. **`src/games/sketch/SketchGame.tsx`**: у игры собственный заголовок. Чтобы добавить в него те же крошки и Home без второго заголовка, нужен явный слот/контракт от модуля и правка его оболочки. Сейчас Back работает через общий стек, но внутренний заголовок Sketch не менялся.
2. **`src/screens/Mission.tsx`**: если при открытии Leave this game нужно автоматически приостанавливать игровой таймер, требуется отдельный управляемый pause/resume-контракт. Сейчас подтверждение навигации не изменяет ход раундов; игрок может пользоваться существующей кнопкой Pause. Нельзя безопасно вызывать старый onBack как паузу: при уже включённой паузе он завершает миссию.
3. Старые browser-check сценарии внутри **`src/games/sketch/`** ищут прежнюю кнопку Parent settings и могут потребовать обновления селекторов на удержание Grown-ups. Эти тесты принадлежат отдельному модулю и не редактировались. Сама игра и проверка её оценки не менялись.

## Проверка

Перед каждым коммитом выполняются:

```sh
npm run typecheck
npm run build
npm run check-content
```

Браузерные сценарии: `src/screens/flow.check.mjs`. Используется уже установленный Playwright, без добавления зависимости в проект. Укажите `FLOW_PLAYWRIGHT_MODULE` (абсолютный путь к его `index.mjs`) и при необходимости `FLOW_CHROME` (Chrome executable). `FLOW_SITE_URL` по умолчанию — `http://127.0.0.1:5175` с production-сборкой.

```sh
node src/screens/flow.check.mjs
# Дополнительные проверки Privacy, прокрутки, Memory/Tic-tac-toe и Escape:
# выставить FLOW_EXTRA_ONLY=1, затем запустить ту же команду
```

Все семь запрошенных сценариев пройдены на **390 и 1280 px**. Дополнительно проверены Enter/Space, отмена короткого удержания, восстановление ответа Ask, новый ID повторной игры, сохранение возраста/времени, возврат из ролика в каталог, Escape, перезагрузка и прежняя позиция прокрутки. На проверенных экранах нет горизонтальной прокрутки, каждый доступный button/link достигается реальными нажатиями Tab. Снимки: `design/screens/flow-*.png`; отчёты: `flow-verification.json` и `flow-navigation-extra.json`.

Для воспроизводимости браузерный тест подставляет ответ FAQ для `/api/ask` и простую страницу в iframe видео. Проверены переходы и UI, а не внешняя модель/YouTube. Физический iPhone не проверялся.
