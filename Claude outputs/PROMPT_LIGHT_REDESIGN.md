# Codex: весь сайт в светлом стиле Bleep (как приветствие), не только первый экран

Репозиторий: Tarlan2006/westcoded-business-cup, ветка main. `git pull --rebase` перед началом. Коммиты без Co-Authored-By и трейлеров Claude. Этот промпт ЗАМЕНЯЕТ PROMPT_START_SCREEN.md и предыдущие тёмные дизайн-промпты (реконструкция, Memory restyle).
Эталон дизайна (7 экранов): https://claude.ai/artifact/9KU1snn3b2T89wPg1grqUp : Greeting, Age, Interests, Hub, Memory, Reward, Desktop. Также приложен скриншот приветствия пользователя. Весь сайт должен выглядеть как этот светлый «Duolingo-подобный» стиль.

## Шаг 0. Аудит
Сравни текущий сайт (https://mission-control.tarlan-b06.workers.dev/) с эталоном. Первым делом перечисли в ответе: что показывается первым, порядок экранов, какие экраны ещё тёмные/не по дизайну, какие файлы за них отвечают. Затем исправляй.

## Поток
Первый запуск (нет профиля в localStorage): Greeting → вопросы (возраст, интересы, затем остальные из нашей логики: nickname вместо имени, длительность 10/20/30 мин; без свободного текста и реального имени) → Hub. Дальше: Hub → игры/Learn/Move/Ask → Reward → Hub. Повторный запуск: сразу Hub. Сохрани всю логику: историю навигации, «Start here»/NextUp, press-and-hold Grown-ups, профиль/XP/ранги/streak, возрастные группы, видео-награду.

## Единая дизайн-система (светлая)
Создай/обнови общие токены (CSS variables в одном месте) и общие компоненты, используй их ВЕЗДЕ: Button (primary/secondary/disabled), OptionCard, Chip, Bubble, Mascot (Bleep), ProgressBar, TopBar, BottomNav, StatChip, ActivityTile.
- Фон #FFFFFF, основной текст #1E293B, вторичный #64748B, границы #E2E8F0, тени-«ступеньки» #CBD5E1/#E2E8F0. Шрифты: Fredoka (заголовки, кнопки, числа; 600-700) + Nunito (текст). Радиусы 16-30px.
- Зелёный #58CC02 (тень #46A302/#37840A), синий #1CB0F6 / выбранное: рамка #84D8FF, фон #DDF4FF, текст #1899D6, фиолетовый #6C47FF/#CE82FF, золото #FFC800 (тень #E5A800, фон #FFF8D6), оранжевый #FF9600 (фон #FFF4E0), красный #FF4B4B (фон #FFF1F1).
- Кнопка primary: градиент `#5FD400 → #4AB300`, тень `0 6px 0 #37840A`, белый текст Fredoka 700 заглавными, letter-spacing .06em, радиус 18px, высота 58px; нажатие translateY(4px) и тень 2px. Disabled: #E5E5E5, текст #AFAFAF.
- Карточки/плитки: белые, рамка 3px #E2E8F0, тень `0 5px 0 #E2E8F0`, радиус 20px.
- Пузырь Bleep: белый, рамка 3px #E2E8F0, тень `0 6px 0 #CBD5E1`, Fredoka 700, хвостик по центру снизу.
- Bleep: антенна лаймовая #58CC02, глаза-дуги #38BDF8; moods happy/giggle/excited/oops; на светлом фоне.
- Верхняя полоса прогресса (в вопросах и играх): трек #E5E5E5 высота 16px, заливка #58CC02 с бликом.
- Нижняя навигация 76px: Home, Learn, Move, Ask, Grown-ups (активная: рамка #84D8FF, фон #DDF4FF). Grown-ups остаётся press-and-hold 1.5 с.
- Контейнер на десктопе: max-width ≈1120px по центру (как на скриншоте: линия-разделитель и кнопка справа внизу).

Плитки по возрасту как сейчас.
- **Игры (Memory, Quiz, Tic-tac-toe, Sketch, Space Scale, Balloons, Move-режимы)**: светлый chrome (TopBar с Back и прогрессом, хлебные крошки «Learn › Игра», заголовок, подзаголовок, Bleep с пузырём внизу). Memory: закрытая карточка фиолетовая `#8B6DFF→#6C47FF` с золотой звездой и тенью `0 6px 0 #4A2FC4`; открытая белая с рамкой #E2E8F0; найденная — рамка #58CC02, фон #F0FFD9, галочка-бейдж; ошибка — рамка #FF4B4B, фон #FFF1F1. Иконки карточек: крупные мультяшные космические (SVG из PROMPT_MEMORY_RESTYLE.md, брать оттуда). - Все ранее тёмные экраны переведи на светлую систему. Если какой-то экран не описан в эталоне, собери его из общих компонентов в том же стиле.

## Требования
- Кнопки ≥44px, фокус виден, контраст ≥4.5:1, `aria-label` на иконках, `prefers-reduced-motion`: без покачивания Bleep и конфетти. Анимации только transform/opacity.
- Сохрани COPPA-решения: nickname вместо имени, чипы вместо свободного текста, всё в localStorage, без камеры/геолокации.
- Не трогай worker/*, логику LLM/TTS/STT и контент.
- Производительность: main chunk не растёт заметно (<110 KB gzip), игры остаются lazy.
