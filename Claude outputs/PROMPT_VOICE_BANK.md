# Промпт для Codex: банк реплик, озвучка клипами, расширение FAQ

Скопируй всё ниже в Codex целиком.

## Контекст

Репозиторий Mission Control (Vite + React + Hono на Cloudflare Workers). Хакатон, сдача завтра в 11:00. Платформа, экраны, агент `/api/ask`, голосовой ввод и игровая логика уже в `main`. Не хватает главного для впечатления: **ведущий сейчас говорит голосом браузера (`speechSynthesis`), он звучит механически**. Нужно заменить его заранее записанными mp3-клипами и добавить контент, чтобы игра не повторялась.

Прочитай перед работой: `docs/PLAN.md`, `shared/types.ts` (тип `Line`), `src/game/content.ts` (как грузятся банки), `src/audio/engine.ts` (как читается `/audio/manifest.json`), `src/game/useBriefing.ts`, `src/screens/Mission.tsx`.

## Как это уже работает (не ломай)

- `src/game/content.ts` читает банки `content/{common,hunt,roadtrip,lava}.json` (массивы строк `Line`) и `content/tasks.json` (задания). Строка принимается, только если `voice === "hq"`, поле `mode` равно имени файла (`common`, `hunt`, `roadtrip`, `lava`), `id` и `text` строки. Если поле `file` задано, клип предзагружается. Возраст `ageBand` бывает `"3-5"`, `"6-8"` или `"all"`.
- Задание в `tasks.json`: `{ id, mode, ageBand, lineIds: string[], durationSec, riddle?: { choices: [string, string], answer } }`. Все `lineIds` должны существовать в банках, иначе задание пропускается. Для `lava` с загадкой `answer` должен быть одним из двух `choices`.
- Аудио-движок берёт клипы из `/audio/manifest.json`. Принимаются формы `{ "clips": { "<id>": "/audio/xxx.mp3" } }` или `{ "clips": [{ id, file }] }`. Путь обязан подходить под `^/?audio/[\w/-]+\.mp3$`. **Если клипа нет в манифесте или не загрузился, игра падает на голос браузера**, поэтому частичный банк безопасен.
- Часть реплик ведущего зашита в `src/game/content.ts` как `localLine("local_...", ...)` (интро режимов, recall, outro, time-up, try-again, 3 praise, 12 кодовых имён, 9+ запасных заданий). Их тоже нужно озвучить: в манифесте должны быть их id.

## Что сделать (в порядке приоритета, коммить после каждого пункта)

### 1. Банк контента (20 мин)
Создай/дополни банки на английском, живо и тепло, как ведущий-аниматор, короткими фразами (до ~14 слов, чтобы клип был 2-5 секунд). Целевой объём:

- `content/common.json`: 12 кодовых имён (`kind: "codename"`, одно слово, **без реальных имён детей**, например Comet, Echo, Fox...), 10 похвал (`praise`), 6 повторов (`retry`, мягкие, без осуждения), 6 переходов (`transition`), 8 фраз памяти (`recall`, вида «Last time you tracked down...»), 4 outro, 3 intro.
- `content/hunt.json` + задания: 24 задания `hunt` в `tasks.json` для `3-5` и `6-8` (обычные безопасные домашние предметы: носок, подушка, книга, что-то синее, круглое, мягкое), по одной-две реплики на задание (`kind: "task"`).
- `content/roadtrip.json`: 14 заданий (объекты за окном: красная машина, жёлтый знак, мост, дерево выше машин), для всех возрастов (`"all"`).
- `content/lava.json`: сирена-объявление, 10 загадок и заданий «замри» (в `tasks.json` для загадок с `riddle`), 6 фраз «баланс/замри».

**Правила безопасности контента (жёсткие):**
- Ничего опасного: нет лестниц, кухни, острых и горячих предметов, розеток, окон, балконов, прыжков с мебели, бега в помещении. Всегда «walk, don't run».
- В Roadtrip никогда не просить расстёгивать ремень или вставать. Один раз в интро напомнить «Keep your seat belt on».
- В Lava только «стой на полу», никаких прыжков и залезания на мебель.
- Без страшного, без соревнования, из-за которого ребёнку обидно (всегда доброе «good try»).
- Не просить назвать имя, адрес, школу.

Поля каждой строки: `{ "id", "voice": "hq", "mode", "kind", "ageBand", "text", "file": "/audio/<mode>/<id>.mp3", "durationMs": 0 }` (`durationMs` заполнит скрипт). Идентификаторы уникальные, вида `hunt_task_sock_01`. После загрузки строк в игру `lineFor(id)` обязан находить любую.

### 2. Скрипт озвучки (20 мин)
Создай `scripts/gen-audio.mjs` (Node, без новых тяжёлых зависимостей) и скрипты в `package.json`: `gen-audio`, `check-content`.

- Читает все банки в `content/*.json` **и** реплики `local_*` из `src/game/content.ts` (способ выбери самый безопасный и не меняющий поведение игры, например вынести их в `content/local-lines.json`, который читают и код, и скрипт, но только если это не ломает типы и сборку).
- Для каждой строки генерирует `public/audio/<mode>/<id>.mp3` (моно, ~64 kbps, 22-24 кГц, нормализация громкости, обрезка тишины в начале и конце) и записывает `public/audio/manifest.json` в формате `{ "clips": { "<id>": "/audio/<mode>/<id>.mp3", ... } }`. Кроме того, добавь все `local_*` реплики и озвучку вопросов квиза 3-5 (`content/quiz.json`) как клипы `quiz_<id>`.
- Кэш по хешу текста и голоса: повторный запуск генерирует только изменившееся. Флаги `--only <prefix>`, `--force`, `--dry-run` (без сети, только считает объём и символы).
- Движок выбирается флагом `--engine`: `piper` (по умолчанию, офлайн, `pip install piper-tts`, модель en_US, чёткий женский или тёплый нейтральный голос), `kokoro` (офлайн), `elevenlabs` (ключ из `ELEVENLABS_API_KEY`) и `aura` (Cloudflare Workers AI, ключ и аккаунт из переменных окружения). Платные движки запускаются только с явным флагом и **никогда не коммить ключи**. Для одного и того же голоса задай `--voice`.
- В конце печатает отчёт: число клипов, символов, суммарный размер, ошибки. Общий размер `public/audio` не больше ~12 МБ.
- Если в твоей среде нет интернета или ffmpeg/модели Piper, **не выдумывай клипы**. Сделай скрипт рабочим, проверь `--dry-run`, и в отчёте напиши точные команды для запуска у нас локально.

### 3. Подключение в приложении (10 мин)
- Проверь, что `lineFor(id).file` и манифест согласованы и `preload` берёт клипы. Убедись, что при отсутствии клипа (например, до запуска скрипта) игра по-прежнему идёт на голосе браузера, без ошибок и без тишины.
- `Quiz.tsx` для 3-5: вопрос сначала играет клип `quiz_<id>`, если его нет, то `speakFallback`.
- Не меняй логику таймеров и состояний `mission.ts`.

### 4. FAQ и фильтр для агента (10 мин)
- `content/faq.json`: расширь с 12 до 30 тем (животные, тело, погода, космос, вода, звуки, огонь только как «почему свеча горит», без опасных экспериментов): `{ keywords, topic, answer }`, ответы 2-3 коротких предложения для ребёнка 6-8, топики должны совпадать с темами `quiz.json`. Добавь также `topic` для нескольких новых вопросов квиза 6-8 (до 16).
- `shared/ask-faq.ts`: исправь шаблон запрета `ignore ... instructions` так, чтобы ловились варианты вроде «ignore all previous instructions», «ignore the above instructions», «forget your rules». Добавь проверку в `check-content` (скрипт проверяет, что запрещённые фразы реально отказываются).

### 5. Проверка контента (5 мин)
`npm run check-content` должен проверять: уникальность `id`, что все `lineIds` из `tasks.json` существуют, формат путей в манифесте, у загадок `answer` входит в `choices`, нет слов-стоп-листа (оружие, насилие, взрослые темы), длина реплики не больше 140 символов. Падает с понятным текстом ошибки.

## Правила
- Не трогай `worker/*`, экраны Ask/Home/Video, `src/state/progress.ts` и стили, кроме строго нужного для пункта 3.
- Весь текст на английском (аудитория США).
- Перед каждым коммитом: `npm run typecheck && npm run build && npm run check-content`.
- Короткие коммиты в `main`: `git pull --rebase origin main`, затем `git push origin main`. Без `Co-Authored-By` и без подписей в сообщениях.
- Не коммить ключи и файлы моделей Piper/Kokoro. В `.gitignore` добавь `scripts/.cache/` и модели. Сами mp3 в `public/audio` **коммить**, они нужны для деплоя.

## Критерии приёмки
1. Сборка и `check-content` зелёные, игра проходится от интро до итогов, даже если `public/audio` пустая.
2. В банках не меньше: 12 имён, 10 похвал, 24 hunt-задания, 14 roadtrip-заданий, 10 lava-задач, и все проходят проверки безопасности.
3. `npm run gen-audio -- --dry-run` печатает отчёт без ошибок; команды запуска для живой генерации описаны в `README.md` (раздел «Озвучка»).
4. `/audio/manifest.json` проходит проверку формата, а id всех озвучиваемых реплик есть в манифесте.
5. FAQ из 30 тем, фильтр ловит «ignore all previous instructions».
