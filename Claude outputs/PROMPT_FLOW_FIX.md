## Проблема

При проверке сайта нашли разрывы в логике перехода между страницами:

1. Кнопка **«Parent settings»** в карточке ребёнка ведёт на страницу «For grown-ups» с математикой «What is 11 + 5?». Для жюри это выглядит как поломка: нет объяснения, зачем вопрос, и он стоит там, где ждут настройки.
2. Первая страница сразу форма. Нигде не сказано, что это за продукт и зачем отвечать на вопросы.
3. Хаб — просто сетка плиток. Непонятно, с чего начать.
4. После игры экран «Nice work, agent!» ведёт только в «Back to activities»: нет «сыграть ещё» и «попробовать другое». Так же заканчивается экран итогов Mission.
5. Кнопка «Back» везде ведёт на главную, хотя пользователь пришёл из конкретного раздела. Нет понятия, где я.

Цель: пользователь всегда понимает, где он, зачем эта страница и что делать дальше.

## Что сделать

### 1. Parent settings без математики
- Убери экран с математическим вопросом (`ParentGate`) из пути. Вместо него кнопка в карточке ребёнка называется **«🔒 Grown-ups»** и открывается **удержанием 1,5 секунды** (кольцо прогресса вокруг кнопки заполняется). Подпись маленьким текстом: «Press and hold». Отпустил раньше: ничего не происходит, кольцо возвращается.
- Для клавиатуры: удерживать Enter или Space те же 1,5 секунды. Для экранных читалок: `aria-label="Grown-ups settings, press and hold for one and a half seconds"`.
- Страница настроек называется «Parent settings», сверху одна строка: «Changes apply right away». После сохранения вернуться в хаб и показать плашку «Saved ✓» на 2 секунды (`role="status"`).
- Файл `Parent.tsx` оставь только для `Privacy`; ненужный код `ParentGate` удали.

### 2. Первая страница объясняет продукт
- Над формой короткий блок: заголовок «Mission Control», подзаголовок «Games, quizzes and videos that get kids moving and learning, so you get a few calm minutes», три метки в ряд: «No account», «No camera», «Progress stays on this device». Затем форма (три шага как сейчас).
- Форму можно разбить на 2 экрана с индикатором «Step 1 of 2: age and time» и «Step 2 of 2: where and what first» с кнопками Next/Back, если так читаемее. Для 1–2 лет второй шаг пропускается.
- Кнопка в конце: «See activities».

### 3. Хаб подсказывает, с чего начать
- В хабе сразу под карточкой ребёнка крупная карточка **«Start here»** с одним занятием: по возрасту, месту и выбору «что первым» (например: 6–8, дома, Think & learn → «Ask Mission Control»; 3–5 → «Quiz»; в машине и Move → «Roadtrip Spy»; 1–2 → «Video library»). Остальные секции ниже как есть.
- Подпись у времени: «10 min planned» нажимается и открывает те же настройки (через удержание не нужно, это не меняет профиль) либо убрать вводящую в заблуждение подпись. Выбери один вариант и опиши в FLOW.md.

### 4. После игры понятный следующий шаг
- Общий компонент «Next up» для экранов `reward` и `results`: кнопка «Play again» (то же занятие), две карточки «Try next» (другие занятия подходящего возраста; для 3–5 после квиза первой идёт «Watch your video reward») и ссылка «Back to activities».
- Крошечные подписи XP и серии остаются.

### 5. Навигация и «где я»
- В `ActivityHeader` везде: слева «← Back» (на предыдущий экран, а не всегда на главную: Ask → Quiz → Back возвращает в Ask, результат → хаб), по центру название раздела и хлебные крошки одной строкой («Learn › Quiz»), справа XP. Рядом с Back иконка 🏠 для прыжка в хаб.
- Реализуй простой стек экранов в `App.tsx` (массив `history`), без новых библиотек. `Back` берёт предыдущий. Перезагрузка страницы может вести в хаб, это нормально.
- Во время игры (Mission, Quiz, Memory, TicTacToe) Back спрашивает «Leave this game?» только если игра уже идёт больше нескольких секунд; сообщение дружелюбное, две большие кнопки.

### 6. Документ потока
Создай `design/FLOW.md` со схемой «экран → кнопки → куда ведут» в виде списка и пометкой, что изменилось. Это нужно команде и для презентации.

## Правила
- Перед каждым коммитом: `npm run typecheck && npm run build && npm run check-content`.

- Не ломай то, что уже работает: возрастные ограничения (1–2 только видео, у 3–5 видео после квиза, крестики-нолики и Ask только 6–8), сохранение профиля, отсутствие регистрации.
