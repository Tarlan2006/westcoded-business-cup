# Промпт для Codex: редизайн сайта (светлая тема, 3 понятных шага)

Скопируй всё ниже в Codex целиком.

---

## Контекст

Репозиторий Mission Control (React 19 + TypeScript + Tailwind 4 + Vite, Cloudflare Worker). Сейчас интерфейс тёмный, «технический» и не слишком понятный. Хакатон, сдача завтра в 11:00, жюри открывает сайт на телефоне и на ноутбуке и оценивает за минуты. Нужно сделать **светлый, красивый, дружелюбный** интерфейс с чётким путём из трёх шагов. **Логику игр и данных не менять, меняем только внешний вид и структуру экранов выбора.**

Прочитай перед работой: `src/index.css`, `src/App.tsx`, `src/screens/Home.tsx` (там `Welcome`, `Home`, `LearnHome`, `ParentSettings`, `LearnPage`, `ActivityTile`, `ProfileCard`), `src/screens/Setup.tsx`, `src/screens/Mission.tsx`, `index.html`, `docs/DESIGN_BRIEF.md` (если есть, иначе не нужен).

## Три шага (главная цель)

**Шаг 1. Welcome (первый вход, когда профиля ещё нет).** Должно быть ясно за 3 секунды: что это, для кого, что делать.
- Крупный заголовок «Mission Control» и подзаголовок одной фразой: «Voice-guided missions that get kids moving, learning, and laughing.»
- Слева или сверху иллюстрация-маскот (заглушка, см. ниже), справа или ниже **выбор возраста ребёнка** тремя большими карточками (вертикально на телефоне, в ряд на ноутбуке):
  - **1–2 years**: «Watch & wonder», иконка видео.
  - **3–5 years**: «Play & learn», иконка игры.
  - **6–8 years**: «Explore & ask», иконка вопроса.
  У каждой карточки под названием короткая строка, что внутри («Songs and videos», «Quizzes, memory, missions», «Ask questions, quizzes, missions»).
- Над выбором мелкий текст: «Grown-ups: pick your child's age to start.»
- Под выбором три значка-обещания в одну строку: **No sign-up**, **Kid-safe**, **Stays on this device**.
- Ссылка Privacy внизу. Никакой регистрации, никаких форм.

**Шаг 2. Hub (после выбора возраста).** Один экран, где **сразу видно, что доступно именно этому возрасту**, без лишнего уровня меню.
- Верх: карточка профиля («Agent Comet», ранг, XP-полоса до следующего ранга, streak, кнопка Parent settings маленькая и спокойная).
- Под ней секции с крупными карточками действий (иконка, название, одна строка, цветная полоса или фон по смыслу):
  - **Move (Active):** Scavenger Hunt, Roadtrip Spy, Floor is Lava (только 3–8). Нажатие открывает экран Setup (шаг 3a).
  - **Learn:** Quiz, Memory (3–8), Ask Mission Control и Tic-tac-toe (только 6–8). Нажатие открывает активность сразу.
  - **Watch:** Video library (для 1–2 это единственный экран, для 3–5 доступно).
- Для 1–2 лет показать только Watch, без пустых секций. Для 3–5 не показывать карточки 6–8.
- Реализуй как новый компонент `Hub` в `src/screens/Home.tsx`, заменив промежуточные экраны `Home` и `LearnHome`. В `App.tsx` пути `home` и `learn` должны вести в этот `Hub`, лишние переходы убери, логику выдачи XP не трогай. Если полностью убрать `learn` рискованно, оставь его как алиас на Hub.

**Шаг 3. Сам экран игры или активности.** Единый каркас для всех:
- Верхняя панель: кнопка Back, название активности, чип XP.
- Основная область по центру, максимально крупная (задание, вопрос, карточки).
- Кнопки внизу или по центру, крупные.
- Экраны **Setup** (режим, место At home / In the car, длительность), **Mission**, **Results**, **Quiz**, **Memory**, **Tic-tac-toe**, **Ask**, **VideoCatalog**, **ParentGate**, **ParentSettings**, **Privacy** приведи к тому же стилю.

## Визуальный стиль

**Светлая тема, как у хорошего детского приложения: много белого, мягкие цвета, скруглённые углы, тёплый тон.**

Все цвета, шрифты и радиусы сделай **CSS-переменными в одном блоке `:root` в `src/index.css`**, чтобы дизайнер потом мог подменить палитру одной правкой. Начальные значения:

```css
:root {
  color-scheme: light;
  --bg: #ffffff;
  --bg-soft: #f4f7ff;          /* фон секций и панелей */
  --surface: #ffffff;          /* карточки */
  --border: #e3e8f5;
  --text: #1b2340;
  --muted: #5b6482;
  --primary: #4f46e5;          /* основной, кнопки */
  --primary-soft: #eceaff;
  --accent: #ffc83d;           /* солнечный акцент */
  --accent-text: #3d2b00;
  --success: #1fa971;
  --coral: #ff6b6b;
  --mint: #dff7ec;
  --radius: 20px;
  --radius-lg: 28px;
  --shadow: 0 6px 24px rgba(40, 52, 120, .10);
  --font-heading: "Fredoka", "Nunito", system-ui, sans-serif;
  --font-body: "Nunito", system-ui, sans-serif;
}
```

- Шрифты Fredoka (заголовки) и Nunito (текст) подключи через Google Fonts в `index.html` с `display=swap`. Всегда держи запасной системный шрифт, чтобы сайт работал и без сети.
- Большие скруглённые карточки (`--radius-lg`), мягкая тень, при наведении и нажатии лёгкий подъём. Основная кнопка залита `--primary`, белый текст, высота не меньше 56 px.
- Контраст текста не ниже 4,5:1 (проверь основные пары), фокус виден (`:focus-visible` с обводкой `--primary`).
- Для каждой секции (Move, Learn, Watch) свой мягкий цвет карточек из палитры (например: Move коралловый и жёлтый, Learn фиолетовый и мятный, Watch голубой). Иконки: простые SVG или эмодзи без внешних файлов. Если делаешь SVG, держи их в одном стиле.
- Анимации лёгкие (появление карточек, подпрыгивание маскота), уважай `prefers-reduced-motion`.
- Таймер в миссии: крупная круглая шкала, цвет меняется на тёплый в последние 10 секунд, без красной паники.

**Маскот (заглушка):** создай `src/components/Mascot.tsx` с простым дружелюбным SVG-роботом в наушниках и пропом `mood: "idle" | "happy" | "thinking"`. Используй на Welcome, в Hub и на экране итогов. Потом дизайнер заменит содержимое компонента своим SVG, поэтому весь SVG держи только внутри этого файла.

## Адаптивность
- Мобильный вертикальный экран 360–430 px в приоритете. Все основные действия достижимы большим пальцем.
- Ноутбук 1280 px: контент по центру, максимальная ширина 1100 px, карточки в 2-3 колонки.
- Минимальные области нажатия 48x48 px (в играх для 3–5 лет 64 px).

## Что нельзя трогать
- `worker/*`, `shared/*`, `src/audio/*`, `src/voice/*`, `src/game/*` (логика и таймеры), `src/state/*`, `content/*`, `scripts/*`.
- В `src/screens/Ask.tsx` над ним работает другой человек: меняй только имена CSS-классов и стили, **не меняй структуру и обработчики**.
- Не добавляй регистрацию, камеру, аналитику, внешние виджеты, платные ресурсы.
- Весь текст интерфейса на английском.

## Порядок работы (коммить после каждого пункта)
1. `index.html` (шрифты) и блок переменных в `src/index.css`, базовые стили (кнопки, карточки, шапка).
2. `Mascot.tsx` и экран `Welcome`.
3. `Hub` с секциями Move / Learn / Watch и профиль-карточкой; правки маршрутов в `App.tsx`.
4. Единый каркас шага 3 и стили `Setup`, `Mission`, `Results`.
5. Стили `Quiz`, `Memory`, `Tic-tac-toe`, `Ask` (только классы), `VideoCatalog`, `Parent*`, `Privacy`.
6. Проверка на ширинах 390 и 1280 px: если в среде есть Playwright или Chromium, сохрани скриншоты Welcome, Hub, Mission, Quiz в `design/screens/`. Если нет, проверь вручную вёрстку по коду и сообщи, что скриншотов нет.

## Правила работы
- Перед каждым коммитом: `npm run typecheck && npm run build && npm run check-content`.
- Короткие коммиты прямо в `main`: `git pull --rebase origin main`, потом `git push origin main`. Без `Co-Authored-By` и подписей.
- Не удаляй существующие тексты и подписи для озвучки: звук привязан к `id` реплик, не к вёрстке.

## Критерии приёмки
1. Новый пользователь за 3 секунды понимает, что делать: Welcome с тремя понятными карточками возраста и тремя обещаниями.
2. После выбора возраста виден Hub, где по этому возрасту сразу доступны нужные действия (для 1–2 только видео).
3. Всё в светлой теме, консистентно, без остатков тёмных фонов.
4. Игры, таймеры, голос, XP и FAQ работают как раньше.
5. Сборка и проверки зелёные, на 390 px нет горизонтальной прокрутки.

В конце коротко опиши, что сделано, какие экраны пока остались «сырыми» и где лежат переменные палитры, чтобы дизайнер мог их подменить.
