# Mission Control: план MVP (westcoded, Business Cup 2.0)

Рабочее название продукта: Mission Control. Браузерный голосовой ведущий активных игр для детей 3-11 лет; покупатель: работающие американские родители 25-45. Дедлайн сдачи: 15 нояб, 12:00 (внутренний дедлайн сдачи: 11:00).

> Код пишут Codex-агенты. Этот файл задаёт архитектуру, контракты и границы файлов. Старый каркас (Next.js, BillCheck) устарел: Агент A удаляет его первым коммитом. Документы `SUBMISSION_CHECKLIST.md` и `PITCH_OUTLINE.md` остаются в силе.

## 1. Главное решение: ведущий выбирает реплики, а не придумывает

- Все реплики ведущего (задания, похвала, реакции, сирена, «3-2-1», кодовые имена) озвучиваются **заранее** бесплатным открытым TTS (Kokoro или Piper) и лежат в статике как mp3.
- Во время игры LLM только **выбирает** из присланных кандидатов: какую похвалу включить, какое задание дать следующим, сколько очков начислить. Свободный текст она не генерирует и не озвучивает.
- Плюсы: $0 за озвучку, нет задержки TTS, ведущий не скажет ребёнку ничего неожиданного, можно работать офлайн (без LLM выбор делается по правилам).
- Минус: меньше «магии». Живую генерацию голоса показываем в питче как дорожную карту.

## 2. Стек ($0)

| Слой | Решение |
|---|---|
| Хостинг | Cloudflare Workers (бесплатный тариф) + статика, один деплой, адрес `*.workers.dev` |
| Фронт | Vite + React + TypeScript + Tailwind, Web Audio API, MediaRecorder, Screen Wake Lock |
| API | Hono на Worker: `POST /api/stt`, `POST /api/turn`, `GET /api/health` |
| Распознавание речи | Workers AI `@cf/openai/whisper-large-v3-turbo` (бесплатная квота 10 000 нейронов в сутки) |
| Выбор реплик | Быстрая малая модель на бесплатном тарифе Groq (OpenAI-совместимый API); имя модели в переменной `LLM_MODEL`, ключ в секрете `GROQ_API_KEY` |
| Озвучка | Заранее сгенерированные mp3 (Kokoro/Piper) в `public/audio/`; запасной вариант `speechSynthesis` |
| Данные | Только localStorage. Сервер ничего не хранит и не логирует тела запросов |
| Оплата | Stripe Payment Link (тестовый режим) за родительским гейтом |

Лимиты Workers Free, которые нельзя забывать: 10 мс процессорного времени на запрос (ожидание сети не считается), 100 000 запросов в сутки, 50 подзапросов. Поэтому не гонять тяжёлые циклы по аудио в Worker.

## 4. Контракты

```ts
// shared/types.ts
export type Mode = "hunt" | "roadtrip" | "lava";
export type AgeBand = "3-5" | "6-8" | "9-11";

export interface Line {
  id: string;            // уникальный, например "hunt_task_frame_01"
  voice: string;         // "hq" (основной голос MVP)
  mode: Mode | "common";
  kind: "intro" | "task" | "item" | "praise" | "retry" | "transition"
      | "recall" | "outro" | "codename" | "sfx";
  ageBand?: AgeBand | "all";
  text: string;          // что произносится (для генерации и субтитров)
  file: string;          // путь в /audio/...
  durationMs: number;
}

export interface Profile {
  id: string;
  codenameId: string;    // id реплики из набора codename, без реальных имён
  ageBand: AgeBand;
  xp: number;
  rank: number;          // 0..N, звание по порогам XP
  streak: number;
  lastPlayedISO: string;
  lastMode?: Mode;
  loreNote: string;      // до 120 символов, без личных данных
}

export interface TurnRequest {
  mode: Mode;
  ageBand: AgeBand;
  round: number;
  elapsedSec: number;
  taskLineIds: string[];        // что было дано в этом раунде
  childSaid: string;            // текст после распознавания, может быть пустым
  candidatePraiseIds: string[]; // из этих id модель обязана выбрать
  candidateNextTaskIds: string[];
  loreNote: string;
}

export interface TurnResponse {
  praiseLineId: string;         // обязательно из candidatePraiseIds
  nextTaskId: string;           // обязательно из candidateNextTaskIds
  scoreDelta: number;           // 0..10
  loreNote: string;             // до 120 символов
  source: "llm" | "fallback";
}
```

HTTP:
- `POST /api/stt`: тело `audio/wav` (16 кГц, моно, 16 бит, до 8 секунд), ответ `{ "text": string }`.
- `POST /api/turn`: тело `TurnRequest`, ответ `TurnResponse`. Сервер проверяет, что возвращённые id входят в кандидаты, иначе подставляет детерминированный выбор (`source: "fallback"`). Любая ошибка модели или лимит 429 не должны ломать игру.

Клиентские интерфейсы (чтобы Агент A мог работать с заглушками, пока Агент B пишет реализацию):
```ts
// src/audio/engine.ts
unlock(): Promise<void>                       // вызвать по первому касанию
playQueue(ids: string[], opts?: { gapMs?: number }): Promise<void>
playSfx(id: "siren" | "tick" | "radio" | "fanfare" | "whoosh"): void
setMusic(on: boolean, opts?: { duck?: boolean }): void
speakFallback(text: string): Promise<void>    // speechSynthesis, только на случай отсутствия mp3
// src/voice/recorder.ts
startRecording(): Promise<void>
stopRecording(): Promise<Blob>                // 16 kHz mono WAV
// src/lib/api.ts
transcribe(wav: Blob): Promise<string>        // при ошибке возвращает ""
turn(req: TurnRequest): Promise<TurnResponse> // при ошибке считает локально (fallback)
```

## 5. Режимы MVP

| Режим | Обязателен | Суть | Голос ребёнка нужен? |
|---|---|---|---|
| Secret Agent Scavenger Hunt | да | Отсчёт 45-60 с, ведущий называет 2-3 предмета (клипы «принеси мне» + предметы + «физическое усложнение»), ребёнок бежит, жмёт **I DID IT** или описывает добычу голосом | необязательно |
| Roadtrip Spy | да | В машине: «первый, кто заметит жёлтый знак…». Две большие кнопки «Игрок 1/Игрок 2 заметил», счёт, без бега | нет |
| Floor is Lava | если успеем | Сирена, 10 секунд на диван, мини-загадки и «замри как статуя». Почти полностью по скрипту | нет (кнопки-ответы) |
| Kitchen Detective, Audio Adventure | нет | в дорожную карту | |

Удержание (всё в localStorage): кодовое имя из 12 заготовок (без реальных имён), XP и звания, ежедневный стрик, «память мира»: реплики-напоминания по последнему режиму («вчера мы спасли базу от лавы»), без вставки имён в озвучку.

Объём контента (минимум для MVP, один голос «hq»): 12 кодовых имён, по 6 intro/outro, 10 похвал, 6 повторов («ещё раз, агент»), 6 переходов, 8 напоминаний; Hunt: 40 предметов + 6 фраз-рамок + 8 усложнений; Roadtrip: 30 объектов + реплики счёта; Lava: сирена, 12 загадок/удержаний, 6 балансов. Итого около 200 клипов по 2-4 секунды.

## 6. Один ход игры

1. Агент A: игра выбирает задание из банка, собирает очередь id и вызывает `playQueue`.
2. Ребёнок: **I DID IT** (без голоса) или **HOLD TO TALK** (до 8 секунд).
3. Голос: `stopRecording` → `transcribe` → текст.
4. `turn(...)` с кандидатами, ответ с выбранными id.
5. Игра включает похвалу, начисляет очки, запускает следующий раунд, пока не истечёт таймер миссии.
6. Конец: итог, XP, звание, стрик, запись `loreNote` и `lastMode`.

Если микрофон запрещён, STT недоступен или API упал, игра продолжается кнопками и локальными правилами. Это обязательное требование.

## 7. Безопасность и приватность (правила для кода и контента)

- Аудио ребёнка существует только в оперативной памяти: не сохранять, не логировать, не отправлять никуда, кроме `/api/stt`; в Worker не писать тела запросов в логи. В политике приватности описать, что аудио используется только для ответа на текущую команду и сразу удаляется.
- Без аккаунтов, без камеры, без реальных имён детей, без аналитики с идентификаторами на экранах ребёнка. Настройки и оплата за родительским гейтом (простая арифметическая задача).
- Контент: никаких заданий «залезь/прыгни на высокое», только безопасные формулировки («на подушки», «на диван, если родитель разрешил»); в машине: «только не отстёгивайся», режим Roadtrip без беготни; перед стартом показывать родителю короткое предупреждение.
- Ни одна реплика LLM не озвучивается напрямую: выбираем только id из заранее проверенных банков.
- Это не юридическая консультация; формулировки политики приватности перед сдачей перечитать людьми.

## 9. Чек-лист проверки (QA)

- Устройства: iPhone Safari, Android Chrome, ноутбук Chrome. Открыть URL в режиме инкогнито.
- Нажатие на «Start mission» разблокирует звук; запись и воспроизведение работают на iOS (WAV через Web Audio).
- Микрофон запрещён: игра проходится кнопками. Нет сети: открытый экран не ломается, есть сообщение.
- Таймер, сирена и клипы не накладываются; экран не гаснет во время миссии.
- Публичный URL без входа, репозиторий публичный, секретов в репозитории нет.

## 10. Риски и запасные варианты

| Риск | Что делаем |
|---|---|
| iOS не играет звук/не пишет | Разблокировка по касанию, запись через Web Audio → WAV, тест на iPhone до заморозки |
| Лимит Groq или сбой модели | Автоматический `fallback` на правила, игра идёт дальше |
| Whisper медленный/выше 10 мс CPU в Worker | Клипы до 8 с, 16 кГц моно; base64 без разворачивания массива в JS; замер CPU, при провале включаем режим «только кнопки» |
| Шум в зале жюри | Кнопки-ответы, субтитры, запасное видео демо |
| Размер статики | Моно mp3 64 kbps, проверять общий размер перед деплоем |
| Не успеваем всё | Приоритет: Hunt и Roadtrip. Lava и память мира только после них |

## 11. Что делает человек (Человек 1: Тарлан)

1. Создать аккаунт Cloudflare (карта не нужна), включить Workers, `npx wrangler login`.
2. Получить бесплатный ключ Groq. Добавить в Cloudflare: секрет `GROQ_API_KEY`, переменную `LLM_MODEL`.
3. Подключить GitHub-репозиторий к автодеплою Cloudflare (Workers Builds или `wrangler deploy` в CI).
4. Создать тестовый Stripe Payment Link и положить URL в `VITE_PAYMENT_LINK`.
5. Проверять сборку и живой URL после каждого крупного пуша.
