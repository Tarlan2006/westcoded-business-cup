# Задача: белая тема для всех экранов после Greeting (убрать фиолетовый)

Референс: mypal_white_design_reference.html (открой в браузере; 7 досок: Greeting, Parent Setup phone/desktop, Video, Mission, Complete, Hub).

## Что менять
Parent Setup и все дальнейшие экраны (Video, Mission, Complete, Hub, игры) сейчас тёмно-фиолетовые. Сделай их белыми, в стиле референса. Логику, тексты, профиль, видео, задания, игры НЕ трогать — только цвета, фоны, границы, тени.

## Токены
- Фон страницы: #FFFFFF. Текст: #1E293B, второстепенный #64748B, подсказки #94A3B8.
- Карточки/инпуты: фон #FFF, граница 3px #E2E8F0, нижняя тень 0 4-6px 0 #E2E8F0 (нажимаемые: #CBD5E1).
- Выбранное: фон #DDF4FF, граница #84D8FF, текст #1899D6.
- Выбранные чипы потребностей: фон #F0FFD9, граница #58CC02.
- Главная кнопка: градиент #5FD400→#4AB300, тень 0 6px 0 #37840A, белый текст. Вторичная (TALK): #3FC3FF→#1CB0F6, тень #1899D6.
- Акценты: gold #FFC800, orange #FF9600, red #FF4B4B.
- Шрифты Fredoka + Nunito, радиусы 16-24px, без фиолетового (#6C47FF, #1C145C, #0F0A3C, #4C35DE убрать везде, включая градиенты и glow).
- Видео-плеер остаётся тёмным (#334155→#1E293B) — это единственный тёмный блок.
- Parent Setup: на десктопе карточка 780px по центру с белой подложкой; на телефоне без карточки, колонкой.
- Иконки только SVG, без эмодзи. Кнопки Hold-to-open и Hold: exit сохранить.

## Приёмка
1. `grep -riE "6C47FF|1C145C|0F0A3C|4C35DE|8B6DFF" src` пусто (кроме иконок карточек Memory, если они часть иллюстрации).
2. npm run build без ошибок, размер основного JS не вырос заметно.
3. Скриншоты 390×844 и 1280×800 для всех экранов совпадают с референсом по цветам.
4. Контраст текста ≥ 4.5:1. Коммиты без Co-Authored-By и без упоминаний Claude. Деплой только по команде «деплой».
