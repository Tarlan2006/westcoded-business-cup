# Промпт для Codex: возрасты, профиль, трек Learn, видео, игры

Скопируй всё ниже в Codex целиком.

---

## Контекст

Репозиторий: Mission Control, веб-игра для детей (B2C, США, родители 25-45). Стек: Vite + React 19 + TypeScript + Tailwind 4, Cloudflare Worker на Hono (`worker/index.ts`), деплой `npm run deploy`. Хакатон, жёсткие правила: без регистрации и логина, всё работает по одной ссылке, сборка `main` не должна ломаться.

Сейчас в `main` уже есть трек Active: режимы Hunt, Roadtrip, Lava (`src/screens/Mission.tsx`, `src/game/*`, `src/state/progress.ts`, `src/screens/Setup.tsx`, `src/screens/Parent.tsx`). Его нельзя ломать.

Прочитай перед началом: `docs/PLAN.md`, `shared/types.ts`, `src/App.tsx`, `src/state/progress.ts`, `src/screens/Setup.tsx`, `src/game/usePushToTalk.ts`, `src/game/content.ts`, `worker/index.ts`.

Твоя задача: превратить продукт в «одно приложение, два трека» для трёх возрастов. Время на работу около 1 часа, поэтому делай в порядке приоритета ниже и коммить после каждого пункта.

## Что строим

Поток: **Welcome → выбор возраста → (выбор трека) → активность → награда (XP) → профиль**.

| Возраст | Что видит ребёнок |
|---|---|
| 1-2 | Только каталог видео. Выбора трека нет. |
| 3-5 | Выбор трека: **Active** (текущий Mission Control) или **Learn** (квиз с озвучкой + игра). После квиза открывается видео как награда. |
| 6-8 | Выбор трека: **Active** или **Learn**. В Learn главное: агент «Ask Mission Control» (вопрос голосом или текстом, ответ голосом и текстом), потом квиз и игры. |

Без аккаунтов. Профиль (кодовое имя, возраст, XP, ранг, стрик) живёт только в `localStorage`, настоящих имён детей не запрашиваем.

## Порядок работы (приоритеты)

### 1. Возрасты и профиль (15 мин, обязательно)
- В `shared/types.ts` замени `AgeBand` на `"1-2" | "3-5" | "6-8"`. Весь код и контент, где был `"9-11"`, перенеси в `"6-8"`. После правки `npm run typecheck` и `npm run build` должны проходить.
- Экран **Welcome/Age**: крупные кнопки 1-2, 3-5, 6-8 (для родителя, текст на английском). Выбор сохраняется в профиль и больше не спрашивается, но меняется в `Parent`.
- Экран **Home**: приветствие по кодовому имени, значок XP/ранга/стрика, плитки доступных активностей по возрасту (правила в таблице выше).
- Расширь `src/state/progress.ts`: `ageBand`, `xp`, `rank`, `streak`, `lastPlayedISO`, счётчики по активностям. Миграцию старых данных сделай без падений (старый формат или пустой localStorage).

### 2. Видео-каталог (10 мин, обязательно)
- `content/videos.json`: массив `{ id, title, channel, ageBand }`, где `id` это ID ролика YouTube. Создай файл с 3 примерами-заглушками `"id": "REPLACE_ME"`: команда подставит реальные ID позже. Записи с `id === "REPLACE_ME"` или пустым `id` экран пропускает, при пустом каталоге показывает мягкую заглушку «More videos coming soon», без ошибок.
- Компонент `VideoCatalog`: сетка карточек, по тапу открывается плеер. Встраивание только через `https://www.youtube-nocookie.com/embed/<id>?rel=0&modestbranding=1&playsinline=1`, **без autoplay**, `allow="encrypted-media; picture-in-picture"`, не меньше 200x200 px. Под плеером подпись «Videos are hosted on YouTube».
- Для возраста 1-2 это единственный экран. Для 3-5 он открывается как награда после квиза.

### 3. Трек Learn для 3-5: квиз с озвучкой и игра (15 мин, обязательно)
- `content/quiz.json`: вопросы вида `{ id, ageBand, topic, question, choices: string[2..3], answer, emoji? }`. Для 3-5 сделай 8 коротких вопросов про цвета, формы, животных и счёт до 5, варианты ответов крупные, с эмодзи. Для 6-8 сделай ещё 8 вопросов про природу и науку (небо, вода, растения, космос).
- Экран **Quiz**: один вопрос на экране, крупные кнопки. Вопрос читается вслух кнопкой «Hear it» (и автоматически при появлении) через `speakFallback` из `src/audio/engine.ts`. После ответа: «Correct!» или мягкое «Good try», +XP (правильный +10, попытка +2). Без таймеров и без штрафов.
- Игра для 3-5: **Memory** (4 пары эмодзи, переворот карт тапом).

### 4. Агент «Ask Mission Control» для 6-8 (20 мин, главное)
Экран **Ask**: большая кнопка микрофона (push-to-talk, используй `usePushToTalk`) и поле для ввода текста. Вопрос отправляется на Worker, ответ показывается текстом и озвучивается `speakFallback`. Под ответом кнопки «Ask another» и «Quick quiz about this» (3 вопроса из `quiz.json` по теме).

**Worker:** добавь новый файл `worker/ask.ts` с маршрутом `POST /api/ask`, в `worker/index.ts` только подключи его одной строкой (другие агенты правят этот файл, не трогай `/api/stt` и `/api/turn`).
- Контракт в `shared/types.ts`: `AskRequest { question: string; ageBand: AgeBand }`, `AskResponse { answer: string; source: "llm" | "faq" | "refusal" }`.
- Запрос в Groq (`GROQ_API_KEY`, модель из `LLM_MODEL`, API совместим с OpenAI chat completions). Таймаут 6 секунд.
- Системный промпт (на английском): ты «Mission Control», добрый научный помощник для ребёнка 6-8 лет; отвечай 2-3 короткими предложениями, простыми словами, с одним понятным сравнением; не используй сложные термины; не обсуждай насилие, оружие, взрослые темы, политику, медицину и опасные эксперименты; не проси и не повторяй личные данные (имя, адрес, школа, телефон); если вопрос небезопасен или не про науку и окружающий мир, мягко откажись и предложи другой вопрос; никаких ссылок и рекламы; без эмодзи и без разметки.
- Серверная защита: вопрос обрезается до 200 символов; перед запросом грубый фильтр по списку запретных слов, при срабатывании сразу возвращай готовый мягкий отказ (`source: "refusal"`) и не вызывай LLM; ответ обрезается до 400 символов, из него вырезаются URL и markdown; после очистки ответ не пустой.
- **Запасной вариант без API**: `content/faq.json` на 12 популярных вопросов (why is the sky blue, why is grass green, why do we sleep, why is the sea salty, why does it rain, what are stars, и т.д.) с ответами в том же стиле. Если LLM недоступен, превысил таймаут, вернул пустое, или ключа нет, ищи лучшее совпадение по ключевым словам в FAQ; если совпадения нет, верни универсальный мягкий ответ «Great question! Let's ask a grown-up and find out together.» Экран должен всегда показывать ответ, никогда не ломаться.
- Распознавание голоса: `/api/stt` пока заглушка и вернёт пустую строку. Тогда используй `SpeechRecognition` / `webkitSpeechRecognition`, если он есть в браузере, а иначе фокусируй текстовое поле с подсказкой «Type your question». Текстовый ввод должен работать всегда.
- Приватность: Worker ничего не пишет в логи и хранилища (никаких KV/D1), вопрос не сохраняется на клиенте, на экране мелким текстом «Mission Control doesn't save your questions».

### 5. Игры для 3-8 (10 мин, если успеваешь)
- **Tic-tac-toe** против компьютера (для 6-8; простая стратегия или minimax, но сложность умеренная, чтобы ребёнок мог выиграть).
- **Memory** для 6-8: 8 пар эмодзи (в 3-5 уже есть вариант на 4 пары, сделай один компонент с параметром размера).
- Победа даёт +XP. Крупные касаемые области (минимум 48x48 px), без перетаскивания.

### 6. Связка активностей (5 мин)
- XP и стрик начисляются из всех активностей единым вызовом из `progress.ts`.

## Правила (важно)
- Не трогай чужие зоны: `/api/stt`, `/api/turn`, `src/audio/*`, `src/voice/*`, `scripts/`, банки Active (`content/hunt.json` и т.д.) правят другие агенты. Если нужен новый метод, используй существующие экспорты.
- Весь текст интерфейса и контента на английском (аудитория США).
- Не добавляй регистрацию, камеру, геолокацию, аналитику и сторонние трекеры. Не отправляй данные детей никуда, кроме `/api/ask` (только текст вопроса) и `/api/stt`.
- Не ломай существующие режимы Active. Перед каждым коммитом: `npm run typecheck && npm run build`.
- Коммиты короткие и частые, прямо в `main`: `git pull --rebase origin main`, потом `git push origin main`. В сообщениях коммитов не добавляй `Co-Authored-By` и другие подписи.
- Если не успеваешь, режь в таком порядке: сначала игры (п. 5), потом квиз для 6-8, но **никогда** не режь п. 1, 2, 4 и работу без API.

## Критерии приёмки
1. `npm run typecheck` и `npm run build` проходят, Active (Hunt/Roadtrip/Lava) работает как раньше.
2. Выбор возраста 1-2 открывает только видео; 3-5 даёт Active или Learn; 6-8 даёт Active или Learn с агентом.
3. На 6-8 вопрос «why is the sky blue» без ключа Groq возвращает ответ из FAQ, а с ключом ответ от LLM, оба показываются текстом и озвучиваются.
4. Запрещённый вопрос получает мягкий отказ без вызова LLM.
5. Профиль (XP, ранг, стрик, возраст) переживает перезагрузку страницы.
6. Всё работает без входа и регистрации.
