# Промпт для Codex (агент редизайна): милые крестики-нолики

Скопируй всё ниже в Codex целиком.

---

## Задача

Переделай игру «крестики-нолики» (`src/screens/TicTacToe.tsx`) так, чтобы она выглядела **милой, живой и детской**, в стиле нового светлого редизайна. Логику победы и ход компьютера сохрани и улучши. Это единственная задача: остальные экраны не трогай.

Параллельно другой агент делает изолированную игру Sketch Artist в `src/games/sketch/**`. Чтобы не было конфликтов, держись своей зоны.

### Разрешено менять:
- `src/screens/TicTacToe.tsx`
- новый файл `src/screens/tictactoe.css` (все классы с префиксом `.ttt-`; подключить `import "./tictactoe.css"` только из `TicTacToe.tsx`)
- новые мелкие SVG-компоненты в `src/screens/ttt/` (например `Piece.tsx`, `Confetti.tsx`)
- `design/screens/` (скриншоты результата)

### Запрещено менять:
`src/App.tsx`, `src/screens/Home.tsx` и другие экраны, `src/index.css` (переменные только читать через `var(--...)`), `shared/types.ts`, `package.json`, `package-lock.json`, `worker/*`, `src/audio/*`, `src/voice/*`, `src/state/*`, `content/*`, `scripts/*`, `src/games/sketch/**`. Не добавляй зависимости. Mascot.tsx только используй, не правь. Не меняй пропсы `TicTacToe` (то, как его вызывает `App.tsx`, должно работать без правок).

## Как должна выглядеть игра

**Настроение:** мягко, пузырьково, радостно, как игрушка. Крупные скруглённые формы, пастельные цвета из текущей палитры (`var(--...)`), тени мягкие, ничего острого и тёмного.

- **Поле 3x3:** белые «карточки-клетки» с крупным скруглением и мягкой тенью на цветной подложке. Клетки не меньше 88 px на телефоне, влезают в 360 px без прокрутки. При наведении и нажатии клетка слегка приподнимается и «пружинит».
- **Фигуры (SVG, не текст):**
  - ребёнок: весёлая звёздочка или сердечко ярким цветом акцента;
  - компьютер: милое облачко или круглый «пузырь» с глазками и улыбкой другого цвета.
  Фигура появляется с анимацией «pop» (масштаб 0 → 1.15 → 1) за 250 мс. Облачко иногда моргает.
- **Ведущий:** сверху маленький Mascot (он уже есть) и речевое облачко с короткой фразой: «Your turn!», «Hmm, let me think...», «Nice move!», «Oh no, you got me!», «It's a tie, great game!». Фразы на английском, добрые, никогда не дразнят проигравшего.
- **Победа:** победная линия подсвечивается, три фигуры подпрыгивают, падает конфетти (лёгкое, на CSS или SVG, 1,5–2 с, без библиотек). При ничьей: мягкое «обнимашки» с сердечками. При проигрыше: без грустного экрана, только «Good game! Want a rematch?».
- **Выбор сложности (2 кнопки-пилюли):** «Easy» (компьютер часто ходит случайно) и «Clever» (блокирует выигрыш, сам выигрывает при возможности, иначе центр, углы). Режим по умолчанию: Easy для ребёнка. Сложность запоминается только в состоянии компонента.
- **Счёт:** маленькая плашка «You 2 · Bleep 1 · Ties 0» (имя компьютера бери то, что уже используется в приложении, не выдумывай новых имён).
- **Кнопки:** «Play again», «Back». Не меньше 48 px, понятные без чтения иконки в дополнение к тексту.
- **Кто ходит первым:** в первой партии ребёнок, дальше по очереди.

## Звук и доступность
- Звук не добавляй (аудио-движок другой агент не трогает). Если в текущем `TicTacToe.tsx` уже вызывается озвучка, оставь вызовы как есть.
- Уважай `prefers-reduced-motion`: без конфетти и прыжков, только мгновенная смена состояния.
- Клетки: `<button>` с `aria-label` вида «Row 1, column 2, empty» или «..., star». Результат партии в `aria-live="polite"`.
- Контраст текста и линий не ниже AA на светлом фоне.

## Приватность и безопасность
- Никаких сетевых запросов, хранилища, камеры и микрофона в этой игре.

## Порядок работы (коммит после каждого пункта)
1. Вынести логику игры в чистые функции внутри `TicTacToe.tsx` (победитель, ход Easy, ход Clever) и проверить их небольшим скриптом или временным тестом вне `package.json`. Проверки: компьютер на Clever никогда не проигрывает при ходе вторым; блокирует и выигрывает.
2. SVG-фигуры и стили поля.
3. Ведущий, фразы, счёт, сложность.
4. Победа, ничья, конфетти, `prefers-reduced-motion`.
5. Проверка на 390 и 1280 px, скриншоты в `design/screens/tictactoe-*.png` (поле, победа, ничья).

## Правила
- Перед каждым коммитом: `npm run typecheck && npm run build && npm run check-content`.
- Перед пушем: `git pull --rebase origin main`. Если конфликт вне разрешённых файлов, остановись и сообщи, не решай его сам.
- Без `Co-Authored-By` и подписей в сообщениях коммитов.

## Критерии приёмки
1. `git diff --stat origin/main...HEAD` показывает только разрешённые пути.
2. Игру можно пройти на телефоне без прокрутки: ход ребёнка, ответ компьютера, победа, ничья, «Play again».
3. На Clever компьютер не проигрывает, на Easy иногда ошибается.
4. Всё выглядит единым стилем со светлой темой, без тёмных блоков и острых углов.
5. Вызов из `App.tsx` не менялся, остальные экраны работают как раньше.

В конце коротко опиши, что сделано, и приложи пути к скриншотам.
