## Почему возникала пауза

В версии `79ac11e` начало речи отменяло таймер моргания и жестов. Обновления маскота после этого зависели от изменения формы рта. При постоянной громкости, в том числе при тишине внутри активного воспроизведения, новое изображение не выводилось. Дыхание было включено только для позы покоя. Контрольный опыт держал канал записи активным с нулевым RMS. В течение 5,20 с все 46 сравнений показали одну и ту же картинку и неподвижный CSS-трансформ. [Замер до исправления](baseline.json)

Нашлись ещё два источника видимых задержек. Последовательность покоя начиналась с удержания глаз открытыми на 3,4 с. При изменении свойств `pose` или `speaking` React заново создавал эту последовательность. Сам HTTP-запрос не блокировал отрисовку. Таймеры записи микрофона и игровые ограничения по времени сохранили своё назначение. Причиной неправильной радости было общее отображение `jump` и `wave` одним взмахом.

## Как изменилось поведение

Один планировщик обслуживает видимых маскотов страницы и измеряет сигнал голоса один раз за такт. У каждого персонажа своё состояние и время его окончания. При смене состояния контроллер сохраняет видимый кадр и смешивает его со следующим за 72 мс. Дыхание продолжается в том числе во время тихой реплики и ожидания ответа. Смена экрана освобождает подписку. За пределами экрана и в скрытой вкладке цикл останавливается. При уменьшенном движении выражение меняется статично, а для возврата в покой назначается одно пробуждение по сроку события.

| Состояние | Что видит ребёнок |
| --- | --- |
| Покой | Дыхание, случайное моргание каждые 2–4 с, иногда двойное. Каждые 8–12 с AIdos ненадолго наклоняет голову и переводит взгляд. |
| Приветствие | Улыбка и взмах рукой при входе или возвращении. После приветствия начинается покой. |
| Слушает | Лёгкий наклон головы, внимательный взгляд и закрытый рот. Микрофон имеет приоритет над озвучкой. |
| Размышляет | Взгляд вверх и в сторону, наклон головы, до двух медленных морганий. Экран снимает состояние при получении результата или отмене. |
| Говорит | Пять форм рта по уровню звука, лёгкие движения корпуса. В паузах губы закрываются. |
| Правильно | Широкая улыбка, обе руки подняты одновременно, два небольших подпрыгивания и возврат в покой. |
| Попробуем ещё | Доброжелательная улыбка, открытые ладони, кивок. При включённом звуке ребёнок слышит ободрение. |
| Ошибка сети | Спокойный наклон и открытые ладони. В Ask остаётся доступен локальный ответ. |

Новые выражения собраны из текущего спрайта. Для радости поднятый рукав перенесён на дальнее плечо. Лицо, тюбетейка и костюм сохранены. Для слушания и размышления используются отдельные слои головы и глаз. Из отдельных иллюстраций всё ещё пригодятся **рука у подбородка** и **поднятый большой палец**. Сейчас их смысл передают взгляд, наклон, кивок и открытые ладони.

Казахская реплика записана голосом iseke: «Сәл қалды, дос! Тағы бір рет көрейік». На английском звучит существующая запись тем же голосом, что и в остальной игре: «Good effort, pal. Ready to try again?». Для буквального «Almost! Let's try again» сервис английского голоса вернул дневной лимит. Обе включённые реплики воспроизводятся из локальных файлов.

## Проверки

В начале минутного видео непрерывно показано более 30 с покоя. Далее идут приветствие, микрофон, ожидание, правильный и неправильный ответы, речь и ошибка сети. В тест включены 5,4 с активного беззвучного канала, который воспроизводил исходную проблему. Видео записано Playwright при 25 кадрах/с. Две локальные реплики добавлены по времени фактического старта Web Audio.

Видимое движение измерено внутри области маскота через каждые 80 мс. Изображение уменьшено вдвое, переведено в оттенки серого и сглажено. Чтобы засчитать движение, не менее 90 пикселей должны изменить яркость минимум на 6 уровней относительно предыдущего принятого кадра. Наибольший интервал составил **0,64 с**. Параметры и список ошибок приведены в [результате измерения](measurement.json). Это проверка наблюдаемого движения на одной записи.

В полной казахской викторине для возраста 6–8 пройдены 16 вопросов, восемь правильных ответов и восемь ошибочных. Дополнительно пройдены три вопроса после видео с ответами «верно / ошибка / верно». Проверены обе эмоции, загрузка ободряющей реплики, самостоятельный возврат в покой и итоговый экран. В Ask проверены тестовый микрофон Chromium, удержанный сетевой ответ и локальный ответ при ошибке сервиса. [Результат викторины](quiz.json)

На окне 390×844 при замедлении CPU в четыре раза приветствие показало 56,6 кадра/с, 95-й процентиль интервала составил 18,2 мс. Сдвигов вёрстки не было. После тишины внутри реального MP3 губы полностью закрылись за 118 мс. Отдельно проверены скрытие, возврат, уменьшенное движение, повторное воспроизведение и отмена речи. Расход батареи на физическом телефоне не измеряли.

## Повторение

Запустите `npm run dev` и откройте `/scripts/mascot-lab/`. Каждая кнопка запускает соответствующее состояние и позволяет прервать предыдущее. Для записи панели задайте `DEV_URL`, для проверки собранного сайта — `SMOKE_URL`. При необходимости укажите `CHROME_PATH`. Скрипт измерения использует OpenCV, NumPy и FFmpeg из `FFMPEG`.

```sh
node scripts/mascot-emotions.check.mjs
python scripts/measure-mascot-recording.py
node scripts/quiz-emotions.check.mjs
node scripts/mascot-frames.check.mjs
node scripts/speech-motion.check.mjs
```
