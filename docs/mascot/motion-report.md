## Кадры

| Движение | Реализация | Покадровый просмотр |
| --- | --- | --- |
| Моргание | Пять положений век. К трём исходным добавлены два промежуточных. При открытии глаз последовательность идёт в обратном порядке. | [Веки](lids.png) |
| Разговор | Пять форм губ. Закрытый, средний и широко открытый рот взяты из исходных кадров. Малое открытие и округлённая форма получены деформацией области губ. | [Рот](mouth.png) |
| Приветствие | Восемь положений. Кисть и предплечье поворачиваются вокруг локтя, с постепенным уменьшением деформации у шва рукава. | [Рука](arm.png) |

В основе каждой позы лежит один из исходных рисунков. Все новые кадры построены локальным морфингом. Участки век, губ и руки упакованы отдельно от трёх базовых поз. Каждый участок просмотрен после кодирования WebP на светлом и тёмном фоне. Первый вариант округлённого рта давал прозрачное пятно на щеке. В итоговой версии контур ограничен областью губ. Прозрачные края руки интерполируются с учётом альфа-канала.

## Воспроизведение

Переход между кадрами длится 64 мс. При прерывании переход начинается с видимого изображения. Условия покоя включают дыхание с периодом 3,6 с и увеличением на 1,2%. Контейнер сохраняет размер. Спрайт загружается по одной ссылке, браузер декодирует все кадры до начала анимации. До готовности спрайта доступен статичный постер.

Канал голоса измеряется через Web Audio AnalyserNode по 1024 отсчётам. Планировщик считывает RMS примерно 30 раз в секунду во время речи. Сглаживание, разные пороги открытия и закрытия и минимальное время удержания защищают от частых скачков. Округлённый рот — выразительная форма для одного из диапазонов громкости. Отдельные фонемы по MP3 не распознаются.

Для системного голоса ритм учитывает события границ слов, паузы, возобновления и завершения. При отсутствии событий границ остаётся плавный слоговой ритм. Невидимый маскот останавливает таймер последовательности, переходы и подписку на измерения. При уменьшенном движении показывается статичная поза.

## Проверка в браузере

В каждом из восьми прогонов открыты приветствие, настройка профиля с реальной репликой и экран видео с 10,3 с покоя. В каждом прогоне зарегистрированы все восемь положений руки, пять положений век и пять форм рта. Ошибок в консоли и необработанных ошибок страницы — 0.

Playwright записал экраны через Chrome DevTools. В каждый MP4 добавлен соответствующий исходный MP3 по времени фактического старта Web Audio. В [коротком превью](aidos-preview.webp) увеличен сам персонаж из браузерной записи.

При отдельном прогоне в Chrome на 390×844 с замедлением CPU в 4 раза средняя частота кадров браузера во время приветствия составила 56,8 кадра/с. Интервал между кадрами на 95-м процентиле — 18,1 мс, максимальный — 18,7 мс. Размер и положение контейнера сохранялись, CLS равен 0. После принудительной тишины во время настоящего MP3 губы полностью закрылись за 134 мс. В проверке паузы системного голоса разговорная поза завершилась за 152 мс.

Проверены выход за пределы экрана, возврат, обработчик скрытия вкладки, уменьшенное движение, отмена и повторное воспроизведение. Системный голос проверен управляемыми событиями браузерного API. Расход батареи и работу на физическом телефоне не измеряли.

## Воспроизведение проверок

Сборка, TypeScript, lint и проверка 1064 ключей локализации прошли. Для повторения откройте собранный сайт локально, задайте `SMOKE_URL` и при необходимости `CHROME_PATH`. Скрипту записи нужен `FFMPEG` с кодеками H.264 и WebP.

```sh
node scripts/mascot-frames.check.mjs
node scripts/record-mascot-motion.mjs
node scripts/unified-voice.check.mjs
```

Для пересборки иллюстраций из исходных ключей запустите `python scripts/pack-mascot-motion.py` с Pillow и NumPy. Скрипт читает исходный спрайт из Git и сохраняет увеличенные области для просмотра в `scripts/.cache/mascot-motion/`.
