# Промпты для Codex-агентов

Каждому агенту сначала дать: «Прочитай `docs/PLAN.md` целиком. Работай только в своих файлах. Перед каждым пушем: `git pull --rebase`, `npm run build`. Коммиты короткие, в `main`.» Затем соответствующий промпт ниже.

---

## Промпт A: Агент A (платформа и интерфейс)

Ты отвечаешь за платформу и все экраны Mission Control (см. `docs/PLAN.md`).

Шаг 1 (первым коммитом, в течение 30 минут):
- Удали старый каркас Next.js (папка `src/` со старым кодом, `next.config.mjs`, `tailwind.config.ts`, `postcss.config.mjs`, `tsconfig.json` старого проекта, `.github/workflows/ci.yml`, `docs/CODEX_TASKS.md`, `docs/IDEA_SWAP.md`) и создай новый скелет: Vite + React + TypeScript + Tailwind, Cloudflare Worker на Hono в `worker/index.ts` (пока только `GET /api/health`), `wrangler.jsonc` со статикой из `dist` и режимом single-page application. Используй официальный плагин Cloudflare для Vite, если он стабилен, иначе схему «vite build + wrangler dev».
- Создай `shared/types.ts` ровно по контракту из `docs/PLAN.md`, раздел 4.
- Переписать `README.md` (что это, как запустить, как деплоить, ссылка на живой URL) и `.env.example` (секреты Worker в `.dev.vars.example`).
- Добавь заглушки для интерфейсов Агента B (`src/audio/engine.ts`, `src/voice/recorder.ts`, `src/lib/api.ts`), если их ещё нет: те же сигнатуры, внутри простые моки (`console.log`, `speechSynthesis`). Агент B заменит их своей реализацией; не меняй сигнатуры.
- Запушь и убедись, что сборка проходит. Напиши Человеку 1, когда скелет готов.

Шаг 2: экраны и игра (только свои файлы):
- Экран родителя: выбор профиля ребёнка (кодовое имя из заготовок, возраст 3-5/6-8/9-11), место (дома или в машине), длительность 10/20/30 минут, голос (пока один). Показать предупреждение по безопасности. Старт без регистрации.
- Экран миссии: крупный круговой таймер, пульсирующий в такт речи аватар, две гигантские кнопки **I DID IT!** и **HOLD TO TALK**, субтитры текущей реплики, кнопка паузы. Минимум текста, работает на телефоне в вертикали. Держи экран включённым (Wake Lock).
- Автомат состояний игры в `src/game/` для Scavenger Hunt (обязательно), затем Roadtrip Spy (две кнопки «Игрок 1/Игрок 2», без голоса) и Floor is Lava (сирена, отсчёт 10 с, удержание/загадки кнопками). Подбор заданий из банков `content/` (формат уточни у владельца контента). Если `/api/turn` не отвечает, `api.turn` возвращает fallback, игра не останавливается.
- Профиль, XP, звания, стрик и «память мира» в localStorage (`src/state/`), экран итогов миссии.
- Страница приватности (аудио ребёнка не хранится, без аккаунтов).

Критерий готовности: на живом URL без входа можно пройти Hunt от открытия до итогов на iPhone Safari и Android Chrome; при отказе в микрофоне всё проходится кнопками.

## Промпт B: Агент B (голос, звук и API)

Ты отвечаешь за звук, запись голоса и серверную часть Mission Control (см. `docs/PLAN.md`). Дождись, пока Агент A запушит скелет (или создай свои файлы и подтяни скелет после `git pull --rebase`).

Свои файлы: `worker/*`, `src/audio/*`, `src/voice/*`, `src/lib/api.ts`.

1. `src/audio/engine.ts` на Web Audio API: `unlock` по касанию (iOS), очередь клипов `playQueue` (клипы из `public/audio/manifest.json`, пауза между клипами), SFX (siren, tick, radio, fanfare, whoosh), фоновая музыка с приглушением во время речи, `speakFallback` через `speechSynthesis`. Предзагрузка клипов миссии. Колбэк уровня громкости для пульсации аватара.
2. `src/voice/recorder.ts`: MediaRecorder или AudioWorklet, запись до 8 секунд, перекодирование в WAV 16 кГц моно 16 бит прямо в браузере (Safari пишет mp4/aac, поэтому не отправляй сырой файл). Обработка отказа в микрофоне: понятная ошибка, игра продолжается кнопками.
3. `worker/` на Hono:
   - `POST /api/stt`: принимает WAV, вызывает Workers AI `@cf/openai/whisper-large-v3-turbo`, возвращает `{ text }`. Проверь схему входа модели, используй эффективное base64 без `[...new Uint8Array(...)]` на большом буфере. Замерь процессорное время (лимит 10 мс на бесплатном тарифе); клип не больше 8 секунд.
   - `POST /api/turn`: формирует короткий запрос к Groq (OpenAI-совместимый API, ключ в секрете `GROQ_API_KEY`, модель в `LLM_MODEL`). Модель получает текст ребёнка и списки кандидатов и возвращает JSON `{praiseLineId, nextTaskId, scoreDelta, loreNote}`. Валидируй: id только из кандидатов, `scoreDelta` 0..10, `loreNote` до 120 символов без личных данных; иначе детерминированный fallback. Таймаут 3 секунды, любая ошибка (в том числе 429) приводит к fallback.
   - Никаких логов с телом запросов и аудио; простой ограничитель частоты по IP; `GET /api/health`.
4. `src/lib/api.ts`: `transcribe` и `turn` по контракту; `turn` содержит тот же fallback локально.

Критерий готовности: цепочка «записал голос → текст → выбор реплики» работает на iPhone Safari и Android Chrome; при выключенном Groq игра идёт на fallback; при отказе микрофона нет падений.

## Промпт C: контент и озвучка (Человек 2 + Codex-помощник)

Ты готовишь контент и пакет аудио для Mission Control (см. `docs/PLAN.md`, разделы 5 и 7).

1. В `content/` создай JSON-банки по схеме `Line` из `shared/types.ts`: `common.json` (кодовые имена, intro, outro, похвалы, повторы, переходы, напоминания), `hunt.json`, `roadtrip.json`, `lava.json`; и дополнительно `tasks.json` с заданиями (id, режим, возрастная группа, список id клипов, длительность, сложность). Тексты по-английски, короткие (до 15 слов), живые, в тоне киношного шпионского ведущего, подходят детям 3-11. Строго соблюдай правила безопасности из раздела 7. Объёмы смотри в разделе 5.
2. Скрипт `scripts/gen-audio.*`: читает банки и озвучивает каждую реплику локально бесплатным движком (предпочтительно Kokoro, запасной Piper), пишет моно mp3 64 kbps в `public/audio/hq/<id>.mp3`, считает `durationMs`, собирает `public/audio/manifest.json`. Скрипт идемпотентный (не пересоздаёт неизменившиеся файлы).
3. Выбери один основной голос с бодрым командным тоном и один-два SFX-набора (рация, сирена, тиканье, фанфары) из свободных по лицензии источников; запиши источник и лицензию в `content/LICENSES.md`.
4. Проверь на слух 10-15 случайных клипов, исправь произношение (ударения, паузы), убедись, что общий размер `public/audio` разумный (желательно до 15 МБ).

Критерий готовности: `npm run build` собирает проект с аудио и манифестом; клипы воспроизводятся из тестовой страницы; в банках нет реплик, которые не прошли проверку на безопасность.
