# Как за 30-60 минут перенастроить каркас под выбранную идею

Каркас устроен как «ввод -> AI-анализ -> структурированный результат (находки, сумма, шаги, готовый текст) -> платная граница». Всё, что зависит от темы, лежит в одном файле: `src/config/product.ts`.

## Шаги

1. `src/config/product.ts`: заменить `name`, `track`, `tagline`, `subtitle`, `audience`.
2. Там же: `input` (подпись, подсказка, пример данных). Пример обязателен, чтобы жюри могло проверить продукт без своих данных.
3. Там же: `systemPrompt`. Сохранить JSON-контракт в конце (поля headline, summary, totalUsd, findings, nextSteps, draft).
4. Там же: `sampleResult`. Это то, что показывается в demo-режиме. Должно соответствовать примеру из шага 2.
5. Там же: `pricing`, `pains`, `steps`, `disclaimer`.
6. Положить ключ в Vercel: `ANTHROPIC_API_KEY` или `OPENAI_API_KEY` (+ `LLM_PROVIDER`).

## Какие идеи ложатся без переделки

| Идея | Подходит | Заметка |
|---|---|---|
| Проверка медицинских счетов | да, это текущий пресет | Фото счёта (OCR) добавить следующим шагом |
| Утечки в подписках | да | Вход: вставленная выписка; findings = подписки, totalUsd = экономия |
| Налоги для самозанятых | да | Вход: список доходов/расходов |
| Зарплатные переговоры | частично | Нужен диалоговый режим, добавить страницу-тренажёр |
| Домашка ребёнка для родителя | частично | Вход: условие задачи; результат: объяснение для родителя |
| Excel, который учит на вашем файле | нет | Нужна загрузка файлов и новый экран |
| Entertainment-идеи (решалка, детектив, игра) | нет | Другой UI: интерактив вместо «анализа». Берём только layout/деплой/paywall |

## Что не менять

- `src/app/api/analyze/route.ts`: rate limit и fallback в demo-режим. Это защита от пустого экрана на питче.
- Вход без регистрации. Не добавлять логин ни под каким предлогом (мгновенный провал).
