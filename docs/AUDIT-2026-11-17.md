## Implemented

| Context | Theme |
|---|---|
| Hub and general setup | Calm shapes and slow soft notes |
| Quiz / Ask | Question marks and curiosity theme |
| Memory / Tic-tac-toe | Geometric patterns |
| Space | Stars, moon and orbit |
| Sketch | Pencil, sketch marks and warm notes |
| Balloons / toddler activity / rewards | Playful circles |
| Hunt | Nature |
| Floor is Lava | Adventure |
| Roadtrip | Journey |

The themes use original procedural Web Audio notes, not downloaded songs or third-party tracks. They share one audio bus and cache only the current music buffer. Music crossfades on theme changes and ducks while speech plays. Frame-level music replaces Mission's independently owned soundtrack; recording hooks own independent pause tokens, so one component cannot accidentally unmute another's microphone pause.

The separate **Music on/off** preference stays in localStorage. **Sound off** remains the master mute. Audio starts only after the existing user gesture/unlock. Music is silent in the video library/player, Privacy and parent/plan pages; voices and YouTube keep their own sound. Hidden tabs, parent dialogs, pending exit dialogs and session finishing pause background audio. A paused Mission also pauses music. Reduced-motion turns decoration animation off. Four decorative glyphs use the current palette, sit near the edges and cannot intercept taps or enter screen-reader navigation. No gameplay rules, quiz answers, rewards or chain animations changed.
