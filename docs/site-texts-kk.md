# AIdos · Қазақша мәтіндерді тексеру

Ағылшын және қазақ тіліндегі мәтіндер экрандар бойынша берілген. Жақша ішіндегі өрістерге ойын барысында ат, сан немесе уақыт қойылады. Тапсырманың дауыстық мәтінін Hunt, Roadtrip және Lava бөлімдерінен қараңыз. Квиздер бастапқы жас топтары бойынша бөлінген.
